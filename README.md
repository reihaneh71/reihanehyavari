# Reihaneh Yavari — Bilingual Personal Landing Page

Static bilingual portfolio (English + Persian) ready for GitHub Pages.

## Structure
- `/index.html` — English
- `/fa/index.html` — Persian (RTL)
- `/styles.css` — shared styles
- `/assets/` — portrait and resume

## Update the current GitHub Pages site
1. Extract this ZIP.
2. Open your GitHub repository: `reihaneh71/reihanehyavari`.
3. Upload **the contents of this folder** to the repository root, preserving the `assets` and `fa` folders.
4. Replace the existing `index.html` and `styles.css` when prompted.
5. Commit the changes.
6. GitHub Pages will redeploy automatically.
